# AI Response Evaluation Guidelines

**Document Version:** 1.0  
**Status:** Portfolio Demonstration  
**Author:** Mariana Camps

## 1. Purpose

This document defines a structured methodology for evaluating AI-generated responses.

The guidelines establish consistent criteria to assess response quality, identify errors, and provide clear reviewer justifications.

The examples and methodology are intended for portfolio demonstration purposes.

## 2. Evaluation Principles

Every AI-generated response should be evaluated according to the following principles:

- Objectivity: Assess the response using defined criteria rather than personal preference.
- Consistency: Apply the same evaluation standards across similar tasks.
- Evidence-based judgment: Support evaluations with specific examples from the response.
- Context awareness: Consider the original prompt and its requirements.
- Transparency: Explain the reasoning behind each evaluation decision.

## 3. Core Evaluation Criteria

### 3.1 Accuracy

Evaluate whether the response contains correct and reliable information.

Check for:
- Factual inaccuracies.
- Unsupported claims.
- Contradictory statements.
- Fabricated information or hallucinations.

### 3.2 Instruction Following

Determine whether the response follows the user's instructions.

Check for:
- Compliance with explicit requirements.
- Correct output format.
- Respect for stated limitations.
- Completion of all requested tasks.

### 3.3 Relevance

Assess whether the response addresses the user's actual intent.

Check for:
- Direct relevance to the prompt.
- Unnecessary information.
- Missing or unrelated content.
- Alignment with the requested subject.

### 3.4 Completeness

Evaluate whether the response covers all relevant aspects of the request.

Check for:
- Missing information.
- Incomplete explanations.
- Unanswered questions.
- Important omitted details.

### 3.5 Clarity and Communication

Assess whether the response is understandable and well organized.

Check for:
- Clear language.
- Logical structure.
- Appropriate terminology.
- Ambiguity or confusing explanations.

### 3.6 Safety

Evaluate whether the response handles potentially harmful or sensitive content appropriately.

Check for:
- Unsafe recommendations.
- Harmful instructions.
- Inappropriate disclosure of sensitive information.
- Missing safety considerations when relevant.

## 4. Evaluation Workflow

Each evaluation should follow these steps:

1. Read and understand the original prompt.
2. Identify the user's explicit requirements.
3. Review the AI-generated response.
4. Assess the response against each applicable criterion.
5. Identify errors, omissions, or inconsistencies.
6. Assign scores according to the scoring rubric.
7. Provide evidence-based justifications.
8. Suggest improvements when necessary.

## 5. Error Classification

| Category | Description |
|---|---|
| Factual Error | Incorrect or misleading information |
| Hallucination | Unsupported or fabricated information |
| Instruction Violation | Failure to follow explicit instructions |
| Irrelevance | Content unrelated to the user's request |
| Incompleteness | Missing relevant information |
| Clarity Issue | Ambiguous or poorly structured response |
| Safety Issue | Potentially harmful or inappropriate content |

## 6. Reviewer Documentation

Each reviewed response should include:

- Original prompt.
- AI-generated response.
- Evaluation scores.
- Identified issues.
- Supporting evidence.
- Reviewer justification.
- Suggested correction.

## 7. Evaluation Limitations

Evaluation results may involve subjective judgment, especially when assessing clarity, relevance, or completeness.

Reviewers should distinguish between objectively verifiable errors and differences in interpretation.

A response should not be classified as incorrect solely because it uses a different valid approach.

## 8. Quality Standard

A high-quality AI response should be accurate, relevant, complete, clear, safe, and consistent with the user's instructions.

All evaluation decisions should be explainable, traceable, and supported by evidence.
